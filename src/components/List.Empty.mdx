# List.Empty

The Empty component renders children when the list has no items. Alternatively, pass a render prop to receive the `isEmpty`, `count`, `isFull`, and `max` props.

</hgroup>

## Usage

```tsx
import { createList } from "@form-atoms/list-atom";

const { List } = createList(myAtom);

function BlankSlate() {
  return <List.Empty>Visible only when the listAtom has no items</List.Empty>;
}
```

## Children Props

When `children` is a render prop, it is called with the following props. The render prop is called on every render, so it decides what to show for each state.

| Name    | Type      | Description                                                  |
| ------- | --------- | ------------------------------------------------------------ |
| isEmpty | `boolean` | Indicates whether the list has no items.                     |
| count   | `number`  | Total count of items in the list.                            |
| isFull  | `boolean` | Indicates whether the list has reached its maximum capacity. |
| max     | `number`  | The maximum number of items allowed in the list.             |

## Examples

<Example of={EmptyStories.EmptyList} >

```tsx
import { fieldAtom, InputField } from "form-atoms";
import { listAtom, createList } from "@form-atoms/list-atom";

const hobbies = listAtom({
  name: "hobbies",
  fields: () => ({ hobby: fieldAtom({ value: "" }) }),
});

const { List } = createList(hobbies);

const Example = () => (
  <List>
    <List.Empty>
      <article>
        <p style={{ textAlign: "center" }}>
          You don't have any hobbies in your list. Start by adding your first
          one.
        </p>
      </article>
    </List.Empty>
    <List.Item>
      {({ fields, remove }) => (
        <fieldset role="group">
          <InputField
            atom={fields.hobby}
            render={(props) => <input autoFocus {...props} />}
          />
          <button type="button" className="outline secondary" onClick={remove}>
            Remove
          </button>
        </fieldset>
      )}
    </List.Item>
  </List>
);
```

</Example>

### Render prop

<Example of={EmptyStories.EmptyListRenderProp} >

```tsx
import { fieldAtom, InputField } from "form-atoms";
import { listAtom, createList } from "@form-atoms/list-atom";

const hobbies = listAtom({
  name: "hobbies",
  fields: () => ({ hobby: fieldAtom({ value: "" }) }),
});

const { List } = createList(hobbies);

const Example = () => (
  <List>
    <List.Empty>
      {({ isEmpty, count }) => (
        <p style={{ textAlign: "center" }}>
          {isEmpty
            ? "You don't have any hobbies in your list yet."
            : `You have ${count} ${count === 1 ? "hobby" : "hobbies"} in your list.`}
        </p>
      )}
    </List.Empty>
    <List.Item>
      {({ fields, remove }) => (
        <fieldset role="group">
          <InputField
            atom={fields.hobby}
            render={(props) => <input autoFocus {...props} />}
          />
          <button type="button" className="outline secondary" onClick={remove}>
            Remove
          </button>
        </fieldset>
      )}
    </List.Item>
  </List>
);
```

</Example>
